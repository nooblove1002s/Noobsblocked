# NOOBONLY1 — v1

## GitHub Pages setup
1. Create a GitHub repository.
2. Upload this entire folder structure.
3. Make sure `index.html` is in the repository root.
4. Open Settings → Pages.
5. Choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
6. GitHub will provide the Pages URL.

## Files
- `index.html` — site structure
- `styles.css` — responsive design/theme
- `js/app.js` — navigation, games, settings, block studio and tools
- `data/games.json` — editable game catalog
- `assets/` — future images/icons

## Important
The starter catalog uses links rather than assuming third-party games permit iframe embedding. Only embed games when their owner/license permits it.

This v1 is intentionally lightweight. The next expansion can add a real block-editor workspace, a stronger WebGL/3D scene editor, project save/export, a larger game catalog, profiles/friends, and more customization.
